# Search Export & Report Documentation

This document covers the procedures for exporting your search results and reporting technical issues within the Athlyte Search platform.

## 1. Exporting Data

The export feature allows you to save your search results locally for offline analysis and record-keeping.

### How to Export

- Generate Results: Perform your search or query on the Athlyte Search Dashboard.
- Initiate Export: Click the "Export" button located at the top right side on the results page.
- Download: The system will automatically generate a file containing your current results.

### Technical Details

- File Format: Results are exported in Excel (.xlsx) format.
- Storage: The file is saved directly to your device's default download folder.
- Content: The export includes all data currently visible in your search results table.

## 2. Reporting an Issue

If you experience bugs, errors, or navigation issues while using the dashboard, you can use the built-in reporting tool to notify the administration.

### How to Submit a Report

- Locate the Button: Click the "Report Issue" button, which is located at the top right of the result screen.
- Describe the Problem: A dedicated window will open. Provide a clear and detailed description of the issue you encountered.
- Submit: Click the submit button within the window.

### Process & Resolution

- Direct Delivery: Your report is sent immediately to the system administrators.
- Bug Resolution: This feedback loop is used to identify and fix technical glitches to improve the overall dashboard experience.
- Registration Context: Note that this feature is part of the standard dashboard utilities available to registered users.

### Navigation

Both modules include a back arrow (located next to the main header) that allows you to return to the Athlyte Search Information Centre homepage at any time.

## 3. Viewing Records

The Records module allows you to browse recordbook data that is available on the platform.

### How to Use Filters

To view records, you must complete the following filter selections in the left sidebar:

- Select Type: Choose between Player or Team stats.
- Stat Category: Once a type is selected, choose a specific category (e.g., Passing, Rushing, Scoring). These categories are dynamically loaded based on the selected sport and type.
- Stat Period: Select the timeframe for the record:
- Game: Single-game records.
- Season: Full-season records.
- Career: All-time career records (available for Player type only).

### Understanding the Results

The results are displayed in the main area of the screen:

- Grouped Statistics: Records are often grouped by the specific metric (e.g., "Stat: Passing Yards"). Each group displays a table of top performers.
- Table Data:
- Entity Name: The name of the Player or Team.
- Value: The numerical achievement for that stat.
- Period (Game/Season): Additional context on which specific game or season the record occurred.

### Navigation & States

- Loading: A "Loading..." indicator appears while data is being fetched.
- No Records: If no data matches your specific filter combination, a "No records found" message will be displayed.
